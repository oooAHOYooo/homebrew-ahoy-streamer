# AHOY Streamer Homebrew Tap

Install the preview on macOS with one command:

```sh
brew install oooAHOYooo/ahoy-streamer/ahoy-streamer
```

Homebrew automatically adds this tap the first time. After that, the short command
also works:

```sh
brew install ahoy-streamer
```

The formula supports macOS 13 and newer on Apple Silicon and Intel. It installs the
standalone AHOY Streamer preview executable; Python is not required. Run
`ahoy-streamer` to open the terminal listening room. Use `brew upgrade ahoy-streamer`
to update and `brew uninstall ahoy-streamer` to remove it.

This is an unofficial third-party tap maintained by the AHOY Streamer project. The
current macOS preview executable is not signed or notarized by Apple. The formula pins
the published release and verifies its SHA-256 checksum.

The latest release and project limitations are documented at
https://github.com/oooAHOYooo/ahoy-streamer-cli/releases.
